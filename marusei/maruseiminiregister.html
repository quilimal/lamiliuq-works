マルセイミニレジ iOS App

個人事業主・小規模店舗向け販売管理アプリ

売った瞬間に、
帳簿まで動く。

レジを締めたら、マルセイ会計に仕訳が飛ぶ。
在庫が減ったら、マルセイ棚卸に返る。
マルセイシリーズで、会計の流れがひとつになります。

Features

01

その場で会計、
その場で記帳。

商品をタップして合計を出し、決済方法を選ぶだけ。レジ締め後にJSONを出力すれば、売上仕訳がマルセイ会計に取り込まれます。

02

マルセイシリーズで
データがつながる。

棚卸から商品マスタを受け取り、売れた分の在庫減を返す。売上仕訳は会計へ。JSON連携でアプリをまたいだ手入力をなくします。

03

電子レシートで
お客様へ即渡し。

印刷不要の画面レシート。上下反転表示でそのままお客様にお見せできます。サブスクリプションでインボイス対応レシートのPDF出力も。

Integration

マルセイシリーズと
強力に連携します。

マルセイミニレジは単体でも使えます。
でも、マルセイ棚卸・マルセイ会計と組み合わせると、在庫管理から帳簿まで一気通貫で動きます。

📦

マルセイ棚卸 → ミニレジ

商品マスタ（商品名・在庫ID）をJSONで受け取り、レジ商品として登録。イベント前の準備がすばやく終わります。

🛒

ミニレジ → マルセイ棚卸

レジ締め後、売れた商品の在庫減JSONを出力。棚卸側に取り込むと在庫数が自動で更新されます。返品分の入庫も反映されます。

📒

ミニレジ → マルセイ会計

売上仕訳JSONをコピーして会計アプリに貼るだけ。決済方法・税区分ごとに仕訳が自動で分かれます（最大6本）。

マルセイ棚卸 連携対応 マルセイ会計 連携対応

Spec List

レジ・会計機能

  • ✓商品タップで素早く会計。数量・値引きも個別設定できます
  • ✓全体値引き対応（割引率・値引額）
  • ✓会計時に現金・カード・QRの区分を記録。仕訳の借方科目に反映されます
  • ✓返品処理対応。返品はセッション内でマイナス集計されます
  • ✓消費税モード：非課税・免税 / 簡易課税・特例 / 本則課税

集計・履歴

  • ✓現セッションをリアルタイム集計（決済方法別・商品別）
  • ✓レジ締め後は履歴として保存。過去セッションをいつでも確認できます
  • ✓締め済みセッションからの再レシート発行・JSON再出力に対応

電子レシート

  • ✓印刷不要の画面レシート。お客様のスマホで撮影してもらう形式
  • ✓上下反転表示で、そのままお客様にお見せできます
  • ✓商品点数が多い場合は自動ページ分割

データ・プライバシー

  • ✓完全ローカル設計。データはiPhone内にのみ保存されます
  • ✓JSONバックアップ・復元に対応
